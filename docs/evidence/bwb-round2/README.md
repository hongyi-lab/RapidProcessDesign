## 浏览器执行

使用同一个本地 UI（3981）与真实计算 API（8842），实际完成：

- 默认分析；网页完整优化得到 41 个候选、基线 304.68kg、选中 250.94kg，搜索相关最紧约束为持续机动功率，额定装载单列为固定贴边条件。
- 查看外形、实际承力截面、俯视与复位视角；A/I/EI 和外翼覆盖来自本次分析。没有全机 FE 热图。
- 点击机动功率约束，显示 M07 工况/状态、载荷 hash、需用/可用功率及配平结果。
- 打开 M10 曲线：横轴真实分钟，显示爬升/巡航/下降边界；残差图有实际评价编号和燃油容差线。
- 把巡航段从 500km 改成 450km 后运行：并列值保留，差值变成“—”，显示比较禁用。
- 在选中硬件上将任务装载从 70 改为 71kg：数值收敛仍显示，但额定装载违约显示红色；未伪装成全流程成功。
- MIT 原生示例真实返回 CL=0.2031783、CD=0.0166523、L/D=12.20120；B1/C1=0.9 被拒绝，预测不保留旧系数为新结果。Cm、舵效、载荷和结构继续不可用。

网页/脚本首次分别评价45/41候选，定位为JSON整数/浮点数表示造成重复缓存和不同配置身份。修复后网页41候选；新增身份与缓存回归，HTTP/CLI小规模逐候选哈希和运行标识一致。相应自动检查在 `../../../demos/bwb-flow/evidence/`。
