# BWB 工程流程：独立本地演示

本目录是独立本地演示，位于仓库 `demos/bwb-flow`。界面3981端口、计算8842端口，仅监听本机，不连接旧应用、不导入旧项目代码。

首次使用需 Python 3.11+ 和 Node 22.13+；在本目录的 `ui` 中运行 `npm ci` 安装锁定依赖。随后 Windows 用户双击 **Start-Demo.cmd**，打开 [本地演示](http://127.0.0.1:3981/)，关闭时双击 **Stop-Demo.cmd**。启动脚本依次查找仓库虚拟环境、可用的本机捆绑运行时和 PATH 中的 Python；也可执行 `./Start-Demo.ps1 -PythonExecutable 'C:\Python312\python.exe'` 指定自己的解释器。

其他系统或手动运行：在本目录执行 `python server.py`，在另一终端进入 `ui` 执行 `npm run dev -- --hostname 127.0.0.1 --port 3981`。Python计算不需要额外第三方包。端口为固定的本地演示地址，不要与同一演示的另一副本同时启动。

2026-09-10归档说明：当前pipeline图的可读性仍需按用户稍后提供的模板重做；本分支先保存现状，暂不开展重绘、算法变更或学术模型替换。

## 对照流程图使用

1. 默认示例自动计算。左侧任务对应M01，几何/厚度/推进等对应M04的候选x。
2. 主视图是可交互的三维BWB：拖动旋转、滚轮缩放、右键平移；切换“外形 / 透明外壳 / 内部梁肋”，可俯视、复位、全屏。几何使用本次计算返回的站位、弦长和后掠；改参数并运行后更新。查看C01燃油闭合和关键结果，点击M01–M12模块查看公式、方法、输出与覆盖边界。
3. M09显示部件账本，M10显示燃油/CG随任务变化；“假设与检查”提供真实迭代记录。
4. 把壁厚从1.2mm改为0.8mm，再运行：比较质量/耗油下降与应力/挠度上升。参数修改就是手动外层更新，没有自动优化或agent。
5. 将功率改成12kW，查看功率不足；把油箱比例改成0.015、巡航段改成1800km，查看燃油耗尽。失败输出不以0冒充性能。
6. “对照流程图”与[主工程规格](../../docs/bwb-engineering-pipeline.md)编号一致。导出JSON可保存本次输入、模型假设、状态、迭代和任务节点；刷新会重置内存基线。

## 模型假设

几何坐标x向后、y向右、z向上；演示使用标量纵向方程，未混用主规格建议的体轴。半翼展站位0/0.2/0.55/1，弦长比1/0.75/0.35/0.12，分段后掠40/32/25度，厚弦比0.14。蒙皮面积代理2.05S，额外翼盒梁帽/腹板独立计质量，另加8kg连接项。几何体积系数0.6；自由空间=0.7总包络体积−结构材料体积，载荷分配0.35自由空间，油箱比例可调，加注系数0.95；这些不证明载荷真正能装入。

气动为 `CL=0.2+aα+0.35δ`，a采用带代表后掠的有限翼斜率；`Cm,CG=0.015−0.35α−0.75δ+(CG_MAC−0.25)CL`；`CD=0.022+CL²/(π·0.8·AR)+0.025δ²`，角度为rad。假设推力沿航迹、作用线过CG。配平后检查α在−6°至12°、δ在±20°及固定控制Cmα<0；这是演示域，不是已验证物理边界。

三维使用Three.js实时网格与OrbitControls；不是把平面图倾斜展示。截面总厚度为 `h(u)=0.14c·4u(1−u)[1−0.5(2u−1)²]`，上下表面为±h/2，u为弦向归一化坐标。该演示对称截面最大厚度0.14c，积分面积0.6×0.14c²，与计算的总包络体积系数一致；它不是经过气动验证的翼型。显示轴为(右、上、后)，单位m。梁肋跟随局部截面，梁位0.20c/0.55c；肋数量、开孔和颜色是布局示意，没有独立尺寸优化或有限元含义。透明模式的两种圆点标出起始CG与气动中心，竖线连接到中面，显示高度不代表它们的真实垂向位置。已参考MIT仓库的structure_param.gif和stress.gif，不复制其几何或声称生成了同等FEA结果。

E=70GPa、结构密度2700kg/m³；燃油密度800kg/m³；螺桨效率0.78、BSFC=0.30kg/kWh，可用功率=额定值×0.85×ρ/1.225。推进安装质量18+额定功率/2.5 kg、系统25+0.12载荷kg、起落架15kg；位置见M09账本。爬升率2m/s、下降率1m/s，速度上限42/45m/s；巡航速度按输入。备份为消耗燃油15%，不可用燃油1.5kg。油箱自身质心固定，整机CG随油重变化。

应力120MPa、挠度≤外翼长3%、载荷空间≥0.12m³是**没有正式工程许用依据的演示阈值**，不取代老师决策。载荷因子仅用于示例瞬时对称拉起，不构成载荷包线。结构厚度和质量在内层固定，不因超应力自动增加；未加入静气弹变形反馈。

## 检查与复现

`python -m unittest -v test_engine.py`：8项数值检验全部通过，包括海平面大气、解析梁/三角形分布载荷收敛、燃油与CG解析守恒、任务步长、配平/载荷映射残差、壁厚权衡和失败状态。精确结果见 `verification.json`。这些检查验证演示计算实现，**没有验证气动或整机物理准确性**。

界面位于ui；已完成类型检查和生产构建。三组几何（翼展6/8/12m）已检查顶点/法向有限、尺寸一致、闭合拓扑和外向绕序，三维网格与计算包络体积相差约0.0154%。复现：先生成包含三个analyze结果的JSON数组，再在ui运行 `node --experimental-strip-types scripts/verify-geometry.mjs <JSON路径>`。初次访问本地开发服务可能触发依赖整理，稍后会自动更新。没有执行浏览器逐控件目视/交互验收；页面HTTP、计算API和构建已实际检查。两张静态流程图另行实际打开并迭代过。

`verification.json`中的原始结果记录于2026-09-09，原启动脚本哈希及启动检查对应迁入仓库前的版本；本次打包的检查另记在该文件的`repository_packaging`字段，不把历史记录写成新位置的完整运行验收。

生成三维检验输入（在本目录执行），然后进入ui运行下列检查：

```sh
python -c "import json; from pathlib import Path; from engine import analyze; Path('.run').mkdir(exist_ok=True); Path('.run/geometry-cases.json').write_text(json.dumps([analyze(),analyze({'span_m':12,'root_chord_m':4.2}),analyze({'span_m':6,'root_chord_m':2.4})]),encoding='utf-8')"
cd ui
node --experimental-strip-types scripts/verify-geometry.mjs ../.run/geometry-cases.json
```

页面仅显示API返回值，不在界面另算一套性能结果。本地工具沿用Sites生成目录；用户已选择只在本地运行，因此未注册/部署在线Site，未接入WebMCP或agent。
